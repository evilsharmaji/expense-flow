# 💰 ExpenseFlow – Smart Expense Tracker

A modern, interactive, and DSA-powered Expense Management Web Application designed to help users track, analyze, and manage daily expenses efficiently.

ExpenseFlow combines practical financial management with core Data Structures and Algorithms concepts, making it an excellent academic and portfolio project for Computer Science students.

https://evilsharmaji.github.io/expense-flow/

## 🚀 Features

### 📊 Dashboard
- Real-time expense overview
- Monthly expense tracking
- Total expense calculation
- Top spending category detection
- Daily average spending analysis

### 💵 Expense Management
- Add new expenses

## 🧠 Data Structures & Algorithms Used

### Doubly Linked List
Used to store expenses dynamically.

- Insert Expense → O(1)
- Traverse Expenses → O(n)
- Delete Expense → O(n)
- Search Expense → O(n)

### HashMap with Chaining
Used for category indexing and quick lookups.

- Put → O(1) Average
- Get → O(1) Average
- Remove → O(1) Average

### Merge Sort
Used for sorting expenses.

- Date Wise Sorting
- Amount Wise Sorting
- Category Wise Sorting

Time Complexity: O(n log n)
