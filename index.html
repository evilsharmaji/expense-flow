Linked List

Core Storage

Expenses are stored as nodes in a doubly linked list. Each node holds expense data and pointers to prev/next nodes. This allows O(1) insertion at the tail.

Node { data, prev, next }
insertTail(expense) → O(1)
deleteNode(id) → O(n)
traverse() → O(n)

Indexing

put(key, value) → O(1) avg
